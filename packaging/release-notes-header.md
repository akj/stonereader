## First-time install

Download the `Setup.exe` asset below and run it. StoneReader is not code-signed yet, so Windows SmartScreen may warn that it "protected your PC". Choose **More info**, then **Run anyway** — with a screen reader, tab to the "More info" link, press Enter, then tab to the "Run anyway" button.

The installer needs no administrator rights. Updating from an installed StoneReader happens in-app and skips this warning.
