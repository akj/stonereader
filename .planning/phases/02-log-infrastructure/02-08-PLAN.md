    Procedure summary (full version in 02-FIXTURE-CAPTURE.md):

    1. **Set up `log.config` for capture.** On the Windows machine, create or edit `%LOCALAPPDATA%\Blizzard\Hearthstone\log.config` to contain at minimum:
       ```ini
       [Power]
       LogLevel=1
       FilePrinting=True
       ConsolePrinting=False
       ScreenPrinting=False
       Verbose=True
       ```

    2. **Restart Hearthstone** to force a fresh log directory. Confirm a new subdirectory exists at `%LOCALAPPDATA%\Blizzard\Hearthstone\Logs\Hearthstone_YYYY_MM_DD_HH_MM_SS\` containing `Power.log`.

    3. **Capture `match_start.log`:**
       - Start a Casual match against the AI Innkeeper.
       - Concede after seeing your starting hand (~30 seconds).
       - Copy `Power.log` to `match_start.log`.

    4. **Capture `mid_game.log`:**
       - Start a Casual match.
       - Play 5-7 turns (mulligan + several plays + draws).
       - While the match is ongoing, copy `Power.log` to `mid_game.log`. (Mid-game = log file does NOT contain a final PLAYSTATE WON/LOST.)

    5. **Capture `game_end.log`:**
       - Start a Casual match.
       - Play to game completion (win or lose).
       - Copy `Power.log` after the game ends.

    6. **Capture `reconnect.log`:**
       - Start a Casual match.
       - Force-quit Hearthstone via Task Manager mid-game.
       - Restart Hearthstone. Reconnect to the match.
       - Hearthstone re-dumps the full game state — this produces a second CREATE_GAME block in Power.log.
       - Copy `Power.log` after reconnection settles.

    7. **(Optional) Capture `battlegrounds.log`:**
       - Play one Battlegrounds match to top-4 minimum (~25 minutes).
       - Copy `Power.log` after.

    8. **Anonymize:** Each `.log` file may contain BattleTags. Open the file in Notepad++ (or `sed -i`) and replace:
       - `PlayerName=<your-tag>` → `PlayerName=Player1`
       - `PlayerName=<opponent-tag>` → `PlayerName=Player2`
       - Any `BnetID=<hi> <lo>` lines — leave the format, replace specific values with `BnetID=1 1` and `BnetID=2 2` consistently per player.

    9. **Truncate to size budget:** If any file exceeds 250KB, truncate to a `\n` boundary:
       ```bash
       head -c 250000 game_end.log > game_end_trimmed.log
       # Then in a text editor, ensure the last line is complete (no partial line at EOF).
       mv game_end_trimmed.log game_end.log
       ```
       The `battlegrounds.log` exception: it can be up to 5 MB. If using git LFS, prefer LFS; otherwise truncate to 2 MB at a `\n` boundary.

    10. **Place files:** Copy all 4-5 captured files into `tests/fixtures/log/` in this repo.

    11. **Verify:** Run `uv run pytest tests/test_services/test_engine.py -v`. The previously-skipped tests should now PASS. If a fixture is rejected (e.g., parser raises on the file), check the anonymization step — `sed` replacing `BnetID=...` with malformed values can confuse hslog.

    Failure modes:
    - Hearthstone wrote no `Power.log`: log.config not configured correctly. Re-check step 1.
    - Test fails with "RegexParsingError": fixture is corrupted. Re-capture without anonymization first to confirm the raw file works, then anonymize incrementally.
    - File too large for git: truncate to 2 MB or use git LFS.
