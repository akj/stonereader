      - OR `0x4000` (MOD_NOREPEAT) into modifiers (Pitfall 5).
      - Allocate the next id, increment.
      - Call `self._frame.RegisterHotKey(hkid, mods_with_norepeat, vk)`.
      - On True: store callback in `_callbacks[hkid]`, append `(hkid, label)` to `_registered`, log info, return True.
      - On False: append `label or "mod=...vk=..."` to `_failed`, log warning at WARNING level, return False.
    - `clear_all() -> None`:
      - Iterate `_registered`, call `self._frame.UnregisterHotKey(hkid)` for each, swallow exceptions per-id with `logger.exception`.
      - Clear `_registered`, `_callbacks`. Do NOT clear `_failed` — startup-failure announcement may still want to read it.
      - Idempotent (safe to call twice — second call iterates an empty list).
    - `failed: List[str]` property returns a list-copy of `_failed`.
    - `_on_hotkey(event: wx.KeyEvent) -> None`:
      - Look up `event.GetId()` in `_callbacks`.
      - If found, call the callback inside try/except; on exception, `logger.exception("global hotkey callback raised; ignoring")`.
      - If not found (id we don't own), return silently.
    - The service NEVER imports `keyboard`, `pynput`, `pywinauto`, `win32con`, or `pywin32`. It uses `wx` plus integer literals for the Win32 constants not exposed by wxPython.

    ```python
    """Global hotkey service: wraps wx.Frame.RegisterHotKey for system-wide chords.

    D-01: hybrid model with shared Ctrl+Shift+<letter> modifier prefix.
    Pitfall 4: registration failures (chord held by another app) are logged
        and accumulated in `failed` so the caller can announce them at startup.
    Pitfall 5: MOD_NOREPEAT (0x4000) is OR'd into modifier flags by default
        so a held chord doesn't flood the speech queue.
    Pitfall 3 / T-2-04: a callback that raises is logged and isolated; other
        chords continue to work.

    Application hotkey id space (Win32 RegisterHotKey docs): 0x0000–0xBFFF.
    We allocate ids starting at 1000 and increment per registration.

    The engine layer (Phase 2) NEVER imports wx — keeping `_global_hotkey` in
    services/ is intentional: it lives next to the other private wx-frame-bound
    services (`_watcher.py`, `_tracker.py`).
    """

    from __future__ import annotations

    import logging
    from typing import Callable, Dict, List, Tuple

    import wx

    logger = logging.getLogger(__name__)

    # Win32 MOD_NOREPEAT — wxPython 4.2.5 does not expose this as wx.MOD_NOREPEAT,
    # but RegisterHotKey accepts arbitrary modifier flags (per MSDN), so OR'ing
    # the integer literal works.
    _MOD_NOREPEAT = 0x4000

    # Win32 application hotkey id space starts at 0x0000; we leave room for any
    # caller-supplied ids by starting at 1000.
    _ID_BASE = 1000


    class GlobalHotkeyService:
        """Register and dispatch system-wide hotkeys via wx.Frame.RegisterHotKey.

        Lifecycle:
            hotkeys = GlobalHotkeyService(frame)
            hotkeys.register(wx.MOD_CONTROL | wx.MOD_SHIFT, ord("R"), callback, "Remaining Deck")
            ...
            hotkeys.clear_all()  # call from MainWindow._on_close BEFORE Destroy()
        """

        def __init__(self, frame: wx.Frame) -> None:
            self._frame = frame
            self._next_id = _ID_BASE
            self._callbacks: Dict[int, Callable[[], None]] = {}
            self._registered: List[Tuple[int, str]] = []
            self._failed: List[str] = []
            frame.Bind(wx.EVT_HOTKEY, self._on_hotkey)

        # ----------------------------------------------------------- Public API

        def register(
            self,
            modifiers: int,
            vk: int,
            callback: Callable[[], None],
            label: str = "",
        ) -> bool:
            """Register a global hotkey.

            Returns True on success, False on Win32 conflict (chord held by
            another app — ERROR_HOTKEY_ALREADY_REGISTERED). On failure, the
            label is appended to `failed` for caller-driven user-facing
            announcement (Pitfall 4).

            MOD_NOREPEAT (0x4000) is OR'd into `modifiers` automatically.
            """
            mods = modifiers | _MOD_NOREPEAT
            hkid = self._next_id
            self._next_id += 1
            ok = self._frame.RegisterHotKey(hkid, mods, vk)
            if not ok:
                logger.warning(
                    "RegisterHotKey failed for %s (mods=0x%x vk=0x%x); skipping",
                    label or f"id={hkid}",
                    mods,
                    vk,
                )
                self._failed.append(label or f"mod=0x{mods:x} vk=0x{vk:x}")
                return False
            self._callbacks[hkid] = callback
            self._registered.append((hkid, label))
            logger.info("Registered global hotkey: %s", label or f"id={hkid}")
            return True

        def clear_all(self) -> None:
            """Unregister every registered hotkey. Idempotent.

            Call from MainWindow._on_close BEFORE Destroy() so the OS hotkey
            table is cleaned up cleanly (Runtime State Inventory).
            """
            for hkid, _label in self._registered:
                try:
                    self._frame.UnregisterHotKey(hkid)
                except Exception:
                    logger.exception("UnregisterHotKey failed for id=%d", hkid)
            self._registered.clear()
            self._callbacks.clear()

        @property
        def failed(self) -> List[str]:
            """Labels of chords that failed to register (e.g. held by another app)."""
            return list(self._failed)

        # ----------------------------------------------------------- Internals

        def _on_hotkey(self, event: "wx.Event") -> None:
            hkid = event.GetId()
            callback = self._callbacks.get(hkid)
            if callback is None:
                return
            try:
                callback()
            except Exception:
                logger.exception("global hotkey callback raised; ignoring")
    ```

    ```python
    def test_register_returns_status(monkeypatch, caplog) -> None:
        """register returns True on success and False on conflict; failed accumulates."""
        wx = pytest.importorskip("wx")
        from stonereader.services._global_hotkey import GlobalHotkeyService

        app = wx.App()
        try:
            frame = wx.Frame(None)
            try:
                # Scriptable RegisterHotKey: first call True, second False.
                results = [True, False]
                calls: list = []

                def fake_register(hkid, mods, vk):
                    calls.append((hkid, mods, vk))
                    return results.pop(0)

                monkeypatch.setattr(frame, "RegisterHotKey", fake_register)

                service = GlobalHotkeyService(frame)
                with caplog.at_level(logging.WARNING):
                    ok1 = service.register(wx.MOD_CONTROL | wx.MOD_SHIFT, ord("R"),
                                           lambda: None, "Remaining Deck")
                    ok2 = service.register(wx.MOD_CONTROL | wx.MOD_SHIFT, ord("O"),
                                           lambda: None, "Opponent Hand")

                assert ok1 is True
                assert ok2 is False
                assert service.failed == ["Opponent Hand"]
                # MOD_NOREPEAT (0x4000) was OR'd into both calls' modifier flag.
                base = wx.MOD_CONTROL | wx.MOD_SHIFT
                assert calls[0][1] == base | 0x4000
                assert calls[1][1] == base | 0x4000
                assert any("RegisterHotKey failed" in rec.message for rec in caplog.records)
            finally:
                frame.Destroy()
        finally:
            app.Destroy()
    ```

    ```python
                assert unreg_calls == [1000, 1001]
                # Second call: no-op.

                assert unreg_calls == [1000, 1001]
            finally:
                frame.Destroy()
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS keyboard hook → wx EVT_HOTKEY | Windows delivers WM_HOTKEY directly to the registered frame. The service trusts wx event delivery; no untrusted-input parsing. |
| Application id space (0x0000–0xBFFF) | We allocate from 1000+; no other code in this app uses RegisterHotKey, so collisions are impossible within-process. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-LIVE-09-01 | Tampering | A registered callback raises and breaks subsequent dispatch | mitigate | `_on_hotkey` wraps `callback()` in try/except + `logger.exception`. Other chords continue to work. Severity: low. |
| T-03-LIVE-09-02 | Denial of Service | Held chord floods the speech queue (Pitfall 5) | mitigate | `MOD_NOREPEAT` (0x4000) OR'd into modifiers in every `register` call. Severity: low. |
| T-03-LIVE-09-03 | Resource Leak | Stale OS hotkey registration after frame close (Runtime State Inventory) | mitigate | `clear_all()` is idempotent; plan 03-06 wires it into `MainWindow._on_close` before `Destroy()`. Process exit also auto-cleans the hotkey table. Severity: low. |
| T-03-LIVE-09-04 | Spoofing / Information Disclosure | Another app registers a conflicting chord and intercepts user intent | accept | Win32 RegisterHotKey is first-come-first-served across processes. If another app holds a chord, our register returns False and we surface that to the user via `failed` (Pitfall 4). The user can then close the conflicting app. Severity: low. |

ASVS L1: V14 (configuration) covered — hotkey ids are assigned deterministically with no user-tunable knobs. No `high`-severity threats.
