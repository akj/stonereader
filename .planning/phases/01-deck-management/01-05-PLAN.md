Close UAT Gap 1 (DECK-01, Test 2): users importing a current-meta deckstring should not be blocked when the bundled card database is older than the deckstring's expansion. Add a graceful-degrade import path that builds placeholder Card entries for unknown DBF IDs (Option A), and surface the specific missing DBF IDs in the strict-mode error dialog (Option C). Together these let the user import partial decks immediately and give the developer concrete diagnostic information when refresh is needed.

Purpose:
- Eliminate the dead-end where a single newer card blocks the entire import
- Make the gap diagnosable from the dialog text alone (the user pasted DBF 122939; the dialog should say so)
- Preserve all existing import behavior — the strict path is unchanged for callers that pass allow_unknown=False (default)

Output:
- `Deck.from_deckstring(..., allow_unknown: bool = False)` parameter; when True, missing DBF IDs become placeholder Cards instead of raising
- A new MissingCardsError(ValueError) subclass that exposes a `missing_dbf_ids: tuple[int, ...]` attribute (clean way to surface IDs without parsing string messages)
- `ImportDeckPresenter.validate_and_import` calls `Deck.from_deckstring(..., allow_unknown=True)` so import always succeeds when the deckstring itself is well-formed; speech announcement adds "{N} unknown cards" suffix when unknown_count > 0
- Error dialog for the truly-broken case (e.g. malformed deckstring) is unchanged; dialog for "Missing cards" path now includes the missing DBF IDs

Rationale (per gap-closure-scope tradeoffs):
- Option A (graceful-degrade) is chosen as the baseline: smallest blast radius, deterministic, no network. Lets users use the import flow today without waiting for a `uv lock --upgrade hearthstone-data` shell-out.
- Option C (surface missing DBF IDs in dialog) is layered on top and is orthogonal — it costs ~5 lines of code and turns a black-box error into actionable diagnostic info.
- Option B (on-demand HearthSim XML fetch) is explicitly rejected for this gap-closure pass: introduces network paths, error states, supply-chain trust, and is out of scope for a major-severity UAT fix. If a future phase wants real refresh, it can add `CardDatabase.refresh()` on top of this work.

```python
def validate_and_import(self, deckstring: str, name: str) -> bool:
    """Validate inputs and import deck. Returns True on success.

    Uses graceful-degrade import (Deck.from_deckstring(..., allow_unknown=True))
    so a deckstring referencing cards from a newer expansion still imports;
    unknown cards become placeholder Card entries. The user is told how many
    cards were unknown via the success announcement (UAT Gap 1, DECK-01).
    """
    if not deckstring.strip():
        self._show_error("Enter a deck code to import.")
        return False
    if not name.strip():
        self._show_error("Enter a name for this deck.")
        return False
    try:
        deck = Deck.from_deckstring(
            deckstring.strip(),
            self._card_db,
            name.strip(),
            allow_unknown=True,
        )
    except MissingCardsError as exc:
        # Should not fire because allow_unknown=True; kept as defense-in-depth
        # in case a future refactor re-enables strict mode.
        self._show_error(self._format_missing_cards_message(exc.missing_dbf_ids))
        return False
    except ValueError:
        self._show_error(
            "Invalid deck code. Check that you copied the full "
            "code from Hearthstone and try again."
        )
        return False
    except TypeError:
        self._show_error(
            "Invalid deck code. Check that you copied the full "
            "code from Hearthstone and try again."
        )
        return False

    save_deck(
        self._db_conn,
        deck.name,
        deck.hero_class,
        deck.format,
        deckstring.strip(),
    )

    unknown_count = count_unknown_cards(deck)
    if unknown_count == 1:
        announcement = f"{deck.name} imported, 1 unknown card"
    elif unknown_count > 1:
        announcement = f"{deck.name} imported, {unknown_count} unknown cards"
    else:
        announcement = f"{deck.name} imported"
    self._speech.speak(announcement)

    if self._on_import_success is not None:
        self._on_import_success()
    return True
```

```python
def _format_missing_cards_message(self, missing_dbf_ids: tuple[int, ...]) -> str:
    """Format the missing-cards error dialog text with specific DBF IDs.

    Invoked when a strict-mode caller hits MissingCardsError. The DBF IDs are
    listed so the user/developer can identify which cards (and thus which
    expansion) the local card database is missing.
    """
    if not missing_dbf_ids:
        return (
            "Some cards in this deck were not found in the card database. "
            "The deck code may be from a newer expansion."
        )
    ids_text = ", ".join(str(d) for d in missing_dbf_ids)
    return (
        f"Some cards in this deck were not found in the card database "
        f"(DBF IDs: {ids_text}). The deck code may be from a newer expansion."
    )
```
